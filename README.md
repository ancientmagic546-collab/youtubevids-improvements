# YouTube Vids Improvements

Minecraft 1.21.11 Fabric client mod — context-aware combat input helper.

## Features
- **Context Action Toggle** (default key **G**)
- Empty hand / Wind Charge → spear sequence
- Sword / Spear → mace sequence
- Fully toggleable; OFF = pure vanilla
- Config: `config/youtubevids.properties`

## Install
1. Install Fabric Loader for 1.21.11
2. Install Fabric API for 1.21.11
3. Drop the release JAR into `.minecraft/mods`

## Build
Push to `main` — GitHub Actions builds and publishes a release with the JAR.
